New package: signed Hasura JWTs, the server client and GraphQL courier, schema index, hook helpers, the Apollo + graphql-ws user client with refresh-before-expiry, `WithHasura`, and the `kk-hasura sync` CLI that renders packages' SQL and metadata templates.

Template variables are validated before rendering (identifiers, literals, integers; manifest `type`) and defaults may use other variables.
