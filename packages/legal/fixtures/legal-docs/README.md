# Fixture: @kaperkunde/legal-docs

A stand-in for the package kaperkunde/legal publishes, shaped as it is (the
documents at their paths, `manifest.json` beside them), linked as the
devDependency that satisfies `@kaperkunde/legal`'s optional peer. Its words are
not anybody's terms. Rewrite `manifest.json` with `node write-manifest.mjs`
after changing a document.
